# Real Estate Source And Safety Reference

부동산 시세, 실거래, 호가, 전세가율, 청약, 규제, 개발 호재, 지역 비교를 다룰 때 사용하는 출처·안전 기준이다. 매수/전세/청약/투자 판단에 영향을 주는 요청에서는 이 문서를 읽고 기준일과 출처를 명시한다.

기준 확인일: 2026-07-08

## 1. 답변 전 확인

| 확인 항목 | 기준 |
|---|---|
| 지역 범위 | 시/구/동, 생활권, 역세권, 특정 단지 단위를 구분한다. |
| 목적 | 실거주, 투자, 전세, 월세, 청약, 갈아타기를 분리한다. |
| 예산/기간 | 매수·전세 예산, 보유 기간, 입주 희망 시점을 확인한다. |
| 대출/세금 | 개인 상황에 따라 달라질 수 있으므로 일반 정보로 제한한다. |
| 기준일 | 실거래, 호가, 규제, 개발 계획, 청약 일정의 기준일을 적는다. |

## 2. 출처 우선순위

| 영역 | 1차 출처 | 보조 출처 | 주의 |
|---|---|---|---|
| 실거래가 | 국토교통부 실거래가 공개시스템 | 부동산 플랫폼 | 계약일/해제 여부/층/면적을 확인한다. |
| 시세/통계 | 한국부동산원, KB 등 통계 | 민간 플랫폼 | 지수, 호가, 실거래를 섞지 않는다. |
| 청약 | 청약홈, 사업주체 공고문 | 언론 기사 | 모집공고문, 자격, 일정 변경을 우선한다. |
| 규제/법령 | 법제처, 국토교통부, 지자체 고시 | 세무/부동산 해설 | 개인 세금·대출 결론은 전문가 확인이 필요하다. |
| 개발 계획 | 국토교통부, 지자체, 철도/공공기관 고시 | 기사, 커뮤니티 | 확정/추진/검토/민간 기대감을 분리한다. |
| 단지 정보 | 등기/관리/단지 공시, 공식 자료 | 플랫폼, 중개 현장 | 세대수, 준공연도, 관리 상태를 확인한다. |

출처 예시:

- 국토교통부 실거래가 공개시스템: `https://rt.molit.go.kr/`
- 한국부동산원: `https://www.reb.or.kr/`
- 청약홈: `https://www.applyhome.co.kr/`
- 국가법령정보센터: `https://www.law.go.kr/`

## 3. 가격 정보 구분

| 용어 | 의미 | 주의 |
|---|---|---|
| 실거래가 | 실제 계약 신고 가격 | 신고 지연, 해제, 층/향/수리 상태 차이를 확인한다. |
| 호가 | 매도자가 제시한 가격 | 거래 성사 가격이 아니므로 실거래와 분리한다. |
| 시세 | 플랫폼 또는 통계상 추정 범위 | 산출 방식과 기준일을 확인한다. |
| 전세가율 | 매매가 대비 전세가 비율 | 같은 면적·시점 기준인지 확인한다. |
| 분양가 | 신규 공급 가격 | 옵션, 발코니, 중도금, 주변 시세와 분리한다. |

## 4. 금지 표현

- “무조건 오른다”, “절대 안 떨어진다”, “안전한 투자”처럼 결과를 보장하지 않는다.
- 실거래가, 호가, 시세, 분양가를 같은 가격처럼 섞지 않는다.
- 개발 호재를 확정된 사업처럼 말하지 않는다.
- 세금, 대출, 청약 자격을 개인별 확인 없이 확정하지 않는다.
- 소수 거래만 있는 단지를 대표 시세처럼 단정하지 않는다.

## 5. 리스크 표시 기준

| 상황 | 반드시 포함할 리스크 |
|---|---|
| 투자 목적 | 금리, 대출 규제, 세금, 거래량, 공급, 전세 수요 |
| 실거주 목적 | 출퇴근, 학교, 생활 인프라, 소음, 관리비, 노후도 |
| 청약 | 자격, 가점, 전매제한, 실거주 의무, 자금 일정 |
| 재건축/재개발 | 사업 단계, 조합 리스크, 분담금, 인허가, 지연 가능성 |
| 전세 | 보증금 안전, 선순위 권리, 역전세, 보증보험 가능성 |
| 지방/비인기권 | 유동성, 인구, 산업 기반, 공급 과잉 |

## 6. 출력 체크리스트

- 분석 기준일과 지역 범위를 표시했는가?
- 실거래/호가/시세/분양가를 분리했는가?
- 개발 호재를 확정, 추진, 검토, 민간 기대감으로 나눴는가?
- 목적별로 실거주/투자/전세/청약 결론을 분리했는가?
- 상승 시나리오, 하락 시나리오, 관망 지표를 모두 제시했는가?
- 세금·대출·청약 자격은 일반 정보이며 전문가 확인이 필요하다고 표시했는가?
