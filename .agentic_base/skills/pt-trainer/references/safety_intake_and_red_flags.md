# PT Safety Intake And Red Flags

운동 루틴, 회복, 재활, 다이어트, 러닝, 사이클, 등산, 웨이트 프로그램을 제안할 때 사용하는 안전 기준이다. 통증, 질환, 수술 이력, 재활, 고강도 운동, 초보자 루틴에서는 이 문서를 읽고 강도와 중단 기준을 명시한다.

기준 확인일: 2026-07-08

## 1. 답변 전 안전 확인

| 확인 항목 | 기준 |
|---|---|
| 목표 | 다이어트, 근력, 체력, 회복, 재활, 대회 준비를 구분한다. |
| 경험 | 초보, 재시작, 중급, 고급을 구분한다. |
| 통증/부상 | 위치, 시작 시점, 통증 강도, 악화 동작, 진단 여부를 확인한다. |
| 질환/수술 | 심혈관, 호흡기, 대사질환, 임신, 수술, 약물 복용 여부를 확인한다. |
| 환경 | 장비, 장소, 주당 가능 횟수, 세션 시간, 수면/피로를 확인한다. |
| 강도 기준 | RPE, 심박존, 대화 가능 여부, 통증 기준을 사용한다. |

정보가 부족해도 초안은 만들 수 있지만, 낮은 강도와 보수적 증량을 기본값으로 둔다.

## 2. 즉시 중단 또는 전문가 상담 신호

아래 신호가 있으면 운동을 강행하지 않고 의사, 물리치료사, 응급 진료 등 적절한 전문가 확인을 우선 안내한다.

| 신호 | 대응 |
|---|---|
| 흉통, 가슴 압박감, 턱/왼팔 방사통 | 운동 중단, 의료 상담 또는 응급 평가 |
| 실신, 심한 어지러움, 호흡곤란 | 운동 중단, 의료 상담 |
| 갑작스러운 심한 통증, 찢어지는 느낌 | 해당 부위 운동 중단, 평가 권고 |
| 저림, 감각 이상, 근력 저하 | 신경 증상 가능성으로 전문가 상담 |
| 관절 부종, 열감, 체중 부하 불가 | 운동 중단, 진료 권고 |
| 수술 직후, 골절, 의사 제한 사항 | 의료진 지시 우선 |
| 임신, 심혈관/대사질환, 고혈압 조절 불량 | 개인 상태 확인 전 고강도 운동 금지 |

## 3. 강도 조절 기준

| 사용자 상태 | 기본 강도 | 증량 기준 | 피해야 할 것 |
|---|---|---|---|
| 초보/재시작 | RPE 4-6, 전신 2-3회 | 1-2주 무통증/회복 양호 | 실패 지점까지 반복, 과한 인터벌 |
| 다이어트 | 지속 가능한 유산소+근력 | 주당 총량 5-10% 이내 | 극단적 칼로리/운동량 |
| 근력 향상 | RPE 6-8, 기술 우선 | 자세 유지 시 볼륨/중량 소폭 증가 | 통증 무시, 매세트 한계 반복 |
| 회복/피로 누적 | RPE 2-4 | 수면/피로 회복 후 | 고강도, 긴 세션 |
| 재활/통증 이력 | 통증 없는 범위, 낮은 볼륨 | 통증 0-2/10 유지 시 | 통증 유발 동작, 빠른 ROM 확장 |
| 대회 준비 | 주기화와 회복 포함 | 기록·피로·통증 기반 | 급격한 피크, 회복일 삭제 |

## 4. 통증 기준

| 통증 수준 | 처리 |
|---|---|
| 0-2/10 | 관찰하며 진행 가능. 다음 날 악화 여부 확인. |
| 3-4/10 | 강도, 범위, 속도, 부하를 낮추고 대체 운동으로 전환. |
| 5/10 이상 | 해당 운동 중단. 반복되면 전문가 상담 권고. |
| 날카로운 통증/저림/불안정감 | 즉시 중단. 운동 처방 대신 평가 권고. |

## 5. 프로그램 작성 기준

- 모든 루틴에 워밍업, 본운동, 쿨다운, 대체 운동, 중단 신호를 포함한다.
- 주간 계획에는 운동일과 휴식일을 함께 둔다.
- 초보자는 운동 종류보다 습관화, 자세, 회복을 우선한다.
- 러닝과 사이클은 거리/시간/강도 중 하나만 먼저 늘린다.
- 웨이트는 중량보다 통제된 자세와 반복 가능한 볼륨을 우선한다.
- 재활 목적은 진단이나 치료가 아니라 일반적인 안전 범위의 움직임 가이드로 제한한다.

## 7. 출력 체크리스트

- 사용자 상태가 부족하면 가정과 제한을 명시했는가?
- 통증/질환/수술/임신 같은 red flag를 확인했는가?
- 세트, 반복, 시간, 강도, 휴식, 대체 운동을 함께 적었는가?
- 중단 신호와 다음 주 증량 기준을 넣었는가?
- 의료 진단, 치료 처방, 약물·보충제 처방으로 넘어가지 않았는가?
