# 여행 생애주기와 예약 상태
이 문서는 여행을 집 출발부터 집 도착까지 이어지는 시간-동선-예약 체인으로 설계할 때 읽는다.

## 1. 기본 관점
- 여행은 `집/출발지`에서 시작해 `집/귀착지`로 끝난다.
- 국내 여행은 보통 `집 -> 역/터미널/공항/렌터카 픽업 -> 목적지 -> 숙소/관광지 -> 집` 흐름으로 본다.
- 국외 여행은 보통 `집 -> 공항/항구 -> 탑승 수속 -> 국제 이동 -> 입국/수하물 -> 목적지 이동 -> 숙소/관광지 -> 귀국 이동 -> 집` 흐름으로 본다.
- 사용자가 "도착 후 일정"만 요청해도, 실제 계획서에는 공항/역/터미널 도착, 숙소 이동, 체크인, 짐 처리, 귀가 여유를 반영한다.
- 일정은 장소 목록이 아니라 `위치 노드`와 `이동 구간`의 연속으로 작성한다.

## 2. 여행 단계
- **월 단위 탐색**: 목적지 후보, 계절성, 평균 날씨, 가격대, 성수기, 축제, 피해야 할 시기를 비교한다.
- **날짜 확정 전**: 항공/열차/숙소 선택지를 가격, 시간, 피로도, 도착 후 활용 가능 시간으로 비교한다.
- **예약 전 기획**: 항공/숙소/식당/투어 후보를 제시하고 예약 우선순위를 정한다.
- **예약 후 운영**: 확정된 항공, 숙소, 식당, 교통권을 고정점으로 삼아 전체 루트를 재배치한다.
- **출발 직전 점검**: 최신 날씨, 영업시간, 휴무, 교통 공지, 입국 요건, 예약 확인서를 다시 확인한다.
- **현장 변경 대응**: 우천, 피로, 예약 실패, 교통 지연, 제외 요청이 생기면 시간/비용/동선 영향을 계산해 대체안을 제시한다.

## 3. 예약 상태 분리
항목마다 예약 상태를 분리해 표시한다.

| 상태 | 의미 | 처리 방식 |
|---|---|---|
| 확정 | 이미 예약했거나 사용자가 고정한 항목 | 변경하지 말고 전체 일정의 기준점으로 둔다 |
| 후보 | 예약 전 비교 대상 | 시간, 비용, 위치, 취소 가능성, 피로도를 비교한다 |
| 예약 필요 | 성수기, 인기 식당, 투어처럼 미리 잡아야 하는 항목 | 예약 마감 위험과 우선순위를 표시한다 |
| 현장 선택 | 예약 없이 상황에 따라 고를 수 있는 항목 | 동선 안의 대체 후보로 둔다 |
| 확인 필요 | 영업시간, 휴무, 수하물, 체크인, 날씨처럼 변동 가능한 항목 | 기준일과 출처를 붙여 최신 확인 대상으로 둔다 |

## 4. 하루 유형
- **첫날**: 집 출발, 공항/역/터미널 이동, 탑승 수속, 도착 후 수하물/입국, 숙소 이동, 체크인 또는 짐 보관을 우선한다.
- **일반 체류일**: 숙소에서 시작해 숙소로 돌아오는 폐쇄 루프로 설계한다.
- **숙소 이동일**: 체크아웃, 짐 보관 또는 배송, 다음 숙소 체크인 가능 시간, 도시 간 이동, 저녁 회복 시간을 우선한다.
- **근교 이동일**: 출발역/버스 정류장 접근, 왕복 막차, 현지 체류 시간, 악천후 대체안을 함께 둔다.
- **귀국/귀가일**: 숙소 출발, 공항/역 도착 권장 시간, 탑승 수속, 귀착 후 집 이동까지 포함한다.

## 5. 마스터 여정 체인
상세 일정 전, 전체 여행을 아래처럼 한 줄 체인으로 잡는다.

| 순서 | 날짜 | 시작 | 종료 | 이동/활동 | 예상 소요 | 버퍼 | 예약 상태 | 비용 |
|---:|---|---|---|---|---:|---:|---|---:|
| 1 | [날짜] | 집 | 공항/역 | 이동 | [시간] | [시간] | 확인 필요 | [금액] |
| 2 | [날짜] | 공항/역 | 목적지 | 탑승/이동 | [시간] | [시간] | 확정/후보 | [금액] |
| 3 | [날짜] | 목적지 도착지 | 숙소/첫 방문지 | 이동 | [시간] | [시간] | 확인 필요 | [금액] |

- 마스터 체인은 항공, 숙소, 주요 식당처럼 바꾸기 어려운 고정점부터 배치한다.
- 고정점 사이의 빈 시간에 관광, 식사, 쇼핑, 휴식을 넣는다.
- 각 블록은 시작 위치와 종료 위치가 이어져야 한다.
- 이동시간만 더하지 말고 대기, 환승, 도보, 수하물, 체크인, 휴식 버퍼를 포함한다.

## 6. 짐과 체크인 처리
- 체크인 전 도착하면 숙소 짐 보관, 역 코인락커, 공항/역 수하물 배송, 바로 관광 가능 여부를 판단한다.
- 큰 캐리어가 있으면 계단 많은 역, 좁은 골목, 긴 도보, 혼잡한 식당 경유를 피한다.
- 공항에서 숙소로 가는 중간 관광은 짐 처리 가능성이 확인될 때만 핵심 일정으로 둔다.
- 체크아웃 후에는 다음 숙소까지 바로 이동할지, 중간 보관 후 관광할지, 늦은 체크아웃을 쓸지 비교한다.

## 7. 확정 정보 보호
- 사용자가 준 항공편, 숙소, 식당, 지도 링크, 준비물, 예산은 임의로 덮어쓰지 않는다.
- 더 나은 선택지가 있어도 "대안"으로 분리한다.
- 예약 후 일정에서는 확정된 시간과 위치를 먼저 잠그고 나머지를 맞춘다.
- 예약 전 일정에서는 후보별로 시간표가 어떻게 달라지는지 비교한다.
