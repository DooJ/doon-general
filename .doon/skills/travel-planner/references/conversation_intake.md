# 대화형 인테이크와 질문 최소화
이 문서는 사용자가 "일본여행"처럼 넓게 말하거나 "7월 대마도 여행"처럼 일부 조건을 이미 준 경우, 추천과 질문의 순서를 정할 때 읽는다.

## 1. 기본 원칙
- 처음부터 모든 정보를 묻지 않는다.
- 사용자가 넓게 말하면 현재 날짜와 가까운 계절을 기준으로 3~5개 후보를 먼저 제시하고, 다음 결정을 위한 핵심 질문 1개를 묻는다.
- 사용자가 월, 지역, 목적지를 이미 주면 그 조건에 맞춰 최소 질문만 하고 바로 초안을 만든다.
- 사용자가 특별한 계획이 없다고 하면, 이동 편의, 날씨, 대표 관광지, 식당 권역, 예산대 기준으로 나머지를 채운다.
- 동행 유형과 여행 목적은 후보 선택의 핵심 기준이다. 가족/커플/친구/혼자와 쇼핑/식도락/관광/휴식에 따라 같은 목적지도 다른 일정으로 설계한다.
- 질문은 계획 품질에 큰 영향을 주는 것만 한다. 한 번에 3개를 넘기지 않는다.

## 2. 요청 넓이별 처리
| 요청 예시 | 해석 | 먼저 할 일 | 물어볼 질문 |
|---|---|---|---|
| 일본여행 | 국가만 정함 | 현재 계절 기준으로 곧 가기 좋은 지역 3~5개 추천 | "언제쯤 갈 예정인가요?" 또는 "누구와 가는 여행인가요?" |
| 여름 일본여행 | 계절만 정함 | 여름 적합/비추천 지역, 날씨 리스크 비교 | "휴양, 식도락, 쇼핑, 관광 중 뭐가 우선인가요?" |
| 7월 대마도 여행 | 월과 목적지 정함 | 7월 날씨/이동수단/권장 박수 기준으로 초안 준비 | "출발지는 어디고 몇 박으로 볼까요?" |
| 오사카 3박 4일 | 목적지와 박수 정함 | 항공/숙소 예약 여부 확인 후 일정 초안 | "항공과 숙소는 예약되어 있나요?" |
| 항공/숙소 예약 완료 | 고정점 존재 | 확정 정보 기준으로 실행 일정 구성 | 부족한 확정 정보만 질문 |

## 3. 넓은 요청의 응답 흐름
사용자가 "일본여행", "동남아 여행", "국내여행"처럼 넓게 말하면 아래 순서로 답한다.

1. 기준일을 표시한다.
2. 현재 월과 가까운 여행 시점을 기준으로 후보 3~5개를 제시한다.
3. 후보마다 추천 이유, 권장 박수, 날씨/계절성, 잘 맞는 동행/목적, 주의점을 짧게 적는다.
4. 사용자가 고를 수 있게 후보를 압축한다.
5. 다음 질문은 1개만 한다.

예시 질문:
- "언제쯤 갈 예정인가요?"
- "누구와 가는 여행인가요? 가족, 커플, 친구, 혼자 중 어디에 가까워요?"
- "휴식, 식도락, 쇼핑, 자연, 도시 관광 중 뭐가 제일 중요해요?"
- "예산을 아끼는 쪽과 편한 동선 중 어느 쪽이 우선인가요?"

## 4. 구체 요청의 응답 흐름
사용자가 "7월 대마도 여행"처럼 월과 목적지를 주면 후보 추천보다 실행 계획에 들어간다.

1. 이미 확정된 조건을 요약한다.
2. 해당 월의 날씨, 성수기, 이동수단, 예약 난이도, 권장 박수를 간단히 판단한다.
3. 계획에 꼭 필요한 1~3개만 묻는다.
4. 답이 없어도 합리적 가정을 두고 초안을 작성한다.

우선 질문 후보:
- 출발지: 집/도시/공항/항구
- 기간: 당일치기, 1박 2일, 2박 3일, 3박 이상
- 예약 상태: 항공/배/기차/숙소 예약 여부
- 인원과 동행자: 혼자, 커플, 친구, 가족, 부모님, 아이
- 여행 목적: 쇼핑, 식도락, 관광, 휴식, 자연, 문화/체험
- 예산대: 가성비, 중간, 여유, 프리미엄

## 5. 장소 선택 후 세부 계획 질문
사용자가 후보 중 장소를 고르면 아래 질문 중 필요한 것만 묻는다.

- 며칠 갈지
- 출발지와 귀착지
- 항공/열차/배 예약 여부
- 숙소 예약 여부
- 꼭 가고 싶은 관광지나 제외할 장소
- 식당 취향과 못 먹는 음식
- 여행 목적 우선순위: 쇼핑, 식도락, 관광, 휴식, 자연, 문화/체험
- 예산대
- 이동 선호와 도보 가능량

특별한 선호가 없으면 다음 기본값으로 진행한다.

- 권장 박수는 이동시간과 첫날/마지막날 활용 가능 시간을 기준으로 제안한다.
- 관광지는 대표 명소 2~3개와 동선상 후보 2~4개를 섞는다.
- 식당은 지역 대표 음식, 숙소 후보 권역, 예약 난이도를 기준으로 고른다.
- 숙소는 이동 중심, 가성비, 조용함, 식당/쇼핑 접근성 같은 테마로 나눈다.
- 동행 유형이 없으면 성인 1~2명 기준으로 잡고, 목적이 없으면 첫 방문은 관광+식도락, 재방문은 식도락+쇼핑/휴식으로 가정한다.

## 6. 질문을 줄이는 기준
- 날짜와 목적지가 모두 없으면 날짜 또는 여행 스타일 중 하나만 먼저 묻는다.
- 후보 선택에 동행자가 큰 영향을 주면 날짜보다 동행 유형을 먼저 묻는다.
- 후보 선택에 목적이 큰 영향을 주면 목적 우선순위를 먼저 묻는다.
- 목적지와 월이 있으면 출발지와 박수만 먼저 묻는다.
- 항공/숙소가 미정이면 후보를 제시하고 예약 후 다시 실행 일정으로 전환한다.
- 항공/숙소가 확정이면 자세한 추천보다 확정 시간에 맞춘 루트 재배치를 우선한다.
- 사용자가 "알아서", "특별한 계획 없어"라고 하면 과도한 질문 없이 MD 추천안으로 채운다.
