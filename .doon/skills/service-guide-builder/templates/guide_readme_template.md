- API, ViewModel, Controller, 저장 정책이 변경될 때

## 검증 방법

1. 로컬에서 가이드 페이지를 연다.
2. 좌측 메뉴, 이전/다음, 강조 표시, 상세 패널을 확인한다.
3. 주요 상태와 오류 화면을 전환한다.
4. 다국어가 있으면 화면 문구와 설명 패널이 함께 바뀌는지 확인한다.
5. 브라우저 콘솔 오류와 모바일/데스크톱 레이아웃 깨짐을 확인한다.
