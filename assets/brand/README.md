# DooN brand assets

## 이름과 표기

- 공식 브랜드: `DooN`
- 워드마크: `DO:ON`
- 명령과 기술 표기: `doon`
- 한국어 호출: `두온`
- 짧은 별칭: `둔`

## 상징

- 두 개의 `O`: Doo와 AI, 사용자 판단과 에이전트 실행
- 콜론: 호출, 연결, 입력에서 실행으로 넘어가는 신호
- `ON`: 활성화되어 준비된 시스템 상태
- 청록과 보라: 서로 다른 두 주체가 연결되어 하나의 작업 흐름을 만드는 모습
- 바깥으로 확장되는 노드: 독립된 플러그인과 전문 스킬

## 파일

- `doon-logo.svg`: 저장소 README와 플러그인 문서에 사용하는 벡터 워드마크
- `doon-hero.png`: 두 코어와 전문 스킬 네트워크를 표현한 README 배너
