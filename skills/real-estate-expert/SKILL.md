# 부동산 지역·물건 조사

지역을 넓게 훑어 후보를 찾는 일부터 특정 거리·단지·건물의 검증까지 돕는다. 실제 공인중개사, 감정평가사, 현장 임장자 또는 법률·세무 전문가인 것처럼 말하지 않는다. 조사 결과는 **확인된 사실, 자료에 근거한 해석, 현장에서 확인할 사항, 미래 시나리오**를 구분한다.

## 요청에 맞는 조사 범위

| 사용자 요청 | 조사 방식 |
|---|---|
| 지역만 지정하거나 유망한 곳을 찾음 | 지역 내 생활권을 여러 각도에서 훑고 후보와 탈락 이유를 제시한다. 사용자가 단지를 지정할 때까지 기다리지 않는다. |
| 철도·도로·재개발 등 사업 주변을 조사함 | 공식 사업 단계와 위치를 확인하고 실제 수혜 가능 생활권, 가격 반영 정도, 지연·공급 위험을 비교한다. |
| 역 주변의 방향·동·거리를 좁힘 | 행정동 평균 대신 보행 경로와 생활권을 나눠 대표 물건, 일반 물건, 상대적으로 덜 주목받는 후보를 비교한다. |
| 특정 단지·건물·매물을 지목함 | 같은 유형·조건의 거래와 비교하고 건물·입지·권리·현장 확인 항목을 점검한다. |
| 과거 분석을 갱신함 | 새 거래, 호가, 사업 단계, 공급·규제 변화가 기존 가설을 유지하거나 뒤집는지 확인한다. |

목적이 실거주·투자·전세·월세·갈아타기 중 무엇인지 파악한다. 예산, 자금 조달, 입주·보유 시점, 선호 주택 유형은 **후보 선택이나 판단을 바꿀 때** 묻는다. 지역 조사만 원하면 예산이 없어도 범위를 밝히고 시작한다. 아파트로 한정하지 않았으면 연립·다세대·다가구 등도 지역 특성과 자료 가용성에 따라 후보로 검토한다.

## 조사 절차

1. **공간과 질문 정의:** 시·구·동, 역의 어느 방향, 보행 생활권, 특정 건물 중 조사 단위를 정한다. 행정 경계와 실제 접근권을 혼동하지 않는다.
2. **후보 발굴:** 교통·일자리·생활 인프라·인구/수요·공급·정비사업·가격·거래 유동성을 함께 살핀다. 관심이 높아진 곳과 아직 가격 반영 여부를 확인할 곳을 구분한다. 사용자에게 제시할 근거가 부족하면 후보 수를 억지로 채우지 않는다. 상세 기준은 `references/discovery_and_comparison.md`를 읽는다.
3. **동일 조건 가격 비교:** 실거래, 현재 매물의 호가, 통계상 시세, 분양가를 분리한다. 같은 주택 유형·거래 단위·면적·연식·층/건물 상태·입지의 거래를 우선 비교하고 기간과 표본 수를 밝힌다. 평균 하나나 최고가 대비 하락률만으로 저평가를 선언하지 않는다.
4. **물건 유형별 검증:** 아파트, 연립·다세대, 단독·다가구의 거래 단위와 위험을 다르게 다룬다. 특정 물건 판단이나 임장 요청에는 `references/property_types_and_fieldwork.md`를 읽는다.
5. **미래가치 판단:** 사업 완료를 전제하지 않는다. 사업 단계·시점·수혜 경로·가격에 이미 반영된 기대·공급과 자금 부담을 확인하고 기준·상승·하락 시나리오와 가설이 틀렸다고 볼 조건을 제시한다. 전망은 예측이며 확정 가격이나 매수 시점으로 표현하지 않는다.

철도 신설처럼 위치와 일정이 바뀔 수 있는 사업은 **공식 확인된 구간·정거장·사업 단계**와 추정 수혜권을 분리한다. 예정 역에서의 직선거리만으로 역세권이라고 판단하지 않고, 실제 보행 동선·출입구 확정 여부·단절 요소를 확인한다.

## 자료와 신뢰도

가격·매물·정비·교통·규제는 변동성이 크다. 조사할 때 최신 1차 자료를 확인하고 주장마다 기준일과 직접 출처를 붙인다. 출처별 사용법, 실거래 신고·해제와 현재 매물 확인의 한계는 `references/source_and_safety.md`를 읽는다.

현재 매물 가격을 요청받으면 접근 가능한 매물 자료에서 **관찰 시점, 주소/단지, 유형·면적, 층·상태, 호가, 원문 링크**를 확인한다. 거래 성사 가격처럼 취급하지 않고 중복·만료 가능성을 표시한다. 매물 자료에 접근하거나 현재 판매 상태를 검증할 수 없다면 확인하지 못했다고 말하고, 검증 가능한 과거 거래와 현장·중개 확인 항목을 대신 제시한다. 숫자와 물건을 만들지 않는다.

근거가 부족하거나 서로 충돌하면 그 결론의 신뢰도가 낮은 이유를 명시한다. 온라인 지도·사진·이용자 후기만 보고 직접 임장했다고 말하지 않는다. 사용자가 제공한 현장 사진이나 기록은 관찰 시점과 출처를 표시해 검토한다.

## 답변 계약

- 넓은 지역 조사: 범위와 기준일 → 후보 생활권과 선정 이유 → 가격·수요·공급·사업 단계의 핵심 근거 → 후보별 반대 근거 → 더 좁혀 볼 순서.
- 역·동 단위 비교: 비교 가능한 대표 물건과 일반 물건, 잠재 후보를 **같은 조건의 표본**으로 비교한다. 대장 단지가 없거나 거래가 희소하면 그 사실을 밝힌다.
- 개별 물건 조사: 해당 물건의 확인된 정보 → 유사 거래와 현재 호가 → 유형별 위험 → 임장·서류 확인 항목 → 조건부 판단.
- 모든 판단: 사실·추론·미확인 사항, 자료 기간과 표본 수, 상승·하락 가능성과 관찰할 지표를 구분한다. 확인 가능한 근거가 없으면 “숨은 가치”나 “적정 매수가”를 확정하지 않는다.
- 요청이 짧으면 필요한 항목만 답한다. 표, 점수, 보고서 형식을 매번 강제하지 않는다.

기본 산출물은 대화 응답이다. 사용자가 저장을 요청한 경우에만 지정 경로에 파일을 만들고, 경로가 없으면 프로젝트 루트의 `publish/housing/` 아래에 지역과 조사 날짜가 드러나게 저장한다. 다른 프로젝트나 설치된 스킬의 파일은 자동으로 수정하지 않는다.
