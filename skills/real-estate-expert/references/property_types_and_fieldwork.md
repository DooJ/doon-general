# 주택 유형별 조사와 임장 준비

특정 단지·건물·매물의 분석 또는 현장 확인 계획을 요청받을 때 읽는다. 온라인에서 확인된 정보와 직접 현장에서 확인해야 할 내용을 분리한다. 등기·건축·임대차·세금의 법적 효력이나 권리 안전성을 이 스킬만으로 확정하지 않는다.

## 유형부터 확인

| 유형 | 가격 비교와 추가 확인 |
|---|---|
| 아파트 | 같은 단지 또는 유사 단지의 면적·층·향·준공연도·수리 상태를 구분한다. 세대수, 주차, 관리비·장기수선, 동 배치, 소음과 출퇴근 동선을 확인한다. 공개 대상 단지는 K-apt 등 관리 자료를 참고한다. |
| 연립·다세대(일상 표현의 빌라) | 건물명보다 실제 주소·호실·거래 단위와 전용면적·대지권을 확인한다. 같은 동의 아파트 평균과 직접 비교하지 않는다. 건축물대장상 용도·위반 여부, 주차·채광·누수·관리 상태, 거래 희소성과 환금성을 확인한다. |
| 단독·다가구 | 호실 하나의 가격인지 건물 전체 매매인지 먼저 확인한다. 대지·연면적, 도로 접면·용도지역, 노후도와 수선비, 실제 임대료·공실·보증금 및 권리관계 자료를 확인한다. 임대수익률은 확인된 비용과 임대차 자료가 없으면 계산하지 않는다. |

다른 주택 유형이나 토지를 포함하면 해당 유형의 거래 단위와 공적 장부를 먼저 확인한다. ‘빌라’처럼 광고상의 이름만으로 법적 주택 유형을 확정하지 않는다.

## 서류로 확인할 것과 남는 한계

- **실거래:** 국토교통부 공개 자료의 계약일, 가격, 면적, 층/대지·연면적, 해제 여부. 단독·다가구 등은 공개 주소가 일부 제한될 수 있으므로 거래와 특정 건물을 억지로 연결하지 않는다.
- **건축물대장:** 용도, 구조, 면적, 사용승인, 위반 표시와 현황의 차이. 온라인 자료만으로 실제 시공 상태를 확인했다고 주장하지 않는다.
- **토지·도시계획:** 지목·면적·용도지역, 도로와 도시계획 사항. 계획 도면과 현장 경계·사용 가능성을 혼동하지 않는다.
- **등기·임대차:** 권리관계, 선순위 권리, 보증금과 점유 상태 등은 거래 전 최신 서류와 이해관계인 확인이 필요하다. 누락된 임대차를 “없다”고 단정하지 않는다.
- **아파트 관리:** 해당 단지가 공개 대상이면 관리비, 장기수선 및 관리 상태를 관련 공시로 확인한다. 공개되지 않은 단지에 같은 자료가 있다고 가정하지 않는다.

서류 접근 권한이나 원문이 없으면 ‘확인 필요’로 남긴다. 중개 광고, 지도, 이용자 후기는 현황을 찾는 단서이며 공적 장부의 대체물이 아니다.

## 임장 계획과 현장 기록

현장에 갈 수 없는 분석에서는 사용자가 확인할 동선과 질문을 제시한다. 역·버스정류장부터 실제 보행 시간, 횡단·경사·야간 보행, 교통·상업 소음, 악취, 침수·배수 흔적, 주차, 건물 외관·공용부, 채광·조망, 공사장과 생활 편의 시설을 목적에 맞게 고른다. 해당 물건의 내부 상태와 임대차·관리 상황은 현장 및 서류 확인으로 별도 남긴다.

임장 후 사용자가 제공한 사진·메모·중개 설명은 관찰 날짜와 출처를 적고, 당초 가설과 일치/불일치한 점을 정리한다. 현장에서 보지 못한 사실을 보았다고 쓰지 않는다. 임장 결과가 가격 비교나 미래가치 판단을 바꾸면 후보 순서를 다시 매긴다.

## 물건 검토의 결과

‘괜찮다/나쁘다’ 대신 **가격 근거, 해당 유형의 강점과 위험, 아직 열람하지 못한 서류, 임장 확인 항목, 판단이 달라질 조건**을 짧게 묶는다. 자금 조달·세금·등기·임대차의 확정적 판단이 필요한 단계는 관련 전문가와 최신 서류 확인으로 연결한다.
