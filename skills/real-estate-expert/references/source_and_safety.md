# 부동산 조사의 출처·신뢰도·안전 기준

가격, 현재 매물, 교통·개발, 규제, 청약, 매수·임대 판단처럼 변동 가능한 사항을 조사할 때 읽는다. 기준 확인일: 2026-10-01. 이 문서의 주소는 조사 시작점이며, 실제 답변에는 이번 조사에서 직접 확인한 페이지와 관찰 날짜를 붙인다.

## 자료별 우선 출처와 한계

| 질문 | 우선 확인할 자료 | 주의 |
|---|---|---|
| 체결된 매매·임대차 가격 | [국토교통부 실거래가 공개시스템](https://rt.molit.go.kr/) | 계약일, 면적·층, 거래 유형, 해제 여부와 조회일을 기록한다. 신고 지연·해제로 자료가 바뀔 수 있다. |
| 지역 가격·거래 추세 | [한국부동산원 R-ONE](https://www.reb.or.kr/r-one/portal/main/indexPage.do) 등 공식 통계 | 지수와 개별 거래 가격은 다른 자료다. 통계의 지역·주택 유형·발표 시점을 확인한다. |
| 철도·도로·정비·공급 | 국토교통부, 철도·사업 시행기관, 해당 지자체의 고시·공고·사업 현황 | 계획·승인·착공·운영 단계를 구분하고 노선·역·일정 변경 가능성을 확인한다. 기사만으로 확정하지 않는다. |
| 청약·분양 | 청약홈과 사업주체의 최신 모집공고 | 분양가·옵션·입주 시점·자격·전매 제한은 공고문과 최신 변경 공고로 확인한다. |
| 단지 관리 | [K-apt](https://www.k-apt.go.kr/web/main/index.do) 등 해당 단지의 공시 | 공개 대상과 갱신 시점을 확인한다. 관리비·장기수선 정보가 모든 건물에 제공되는 것은 아니다. |
| 건물·토지 현황 | [정부24 건축물대장](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=15000000098&tp_seq=03), 토지대장, 토지이용계획 등 최신 공적 자료 | 공부와 실제 현황이 다를 수 있다. 열람하지 않은 기록을 확인했다고 쓰지 않는다. |
| 현재 판매 매물·호가 | 접근 가능한 매물 원문, 중개 확인 | 광고의 관찰 시점·가격 수정·중복·판매 종료 가능성을 표시한다. 원문이 없으면 현재 매물로 단정하지 않는다. |
| 등기·임대차·세금·대출 | 해당 시점의 원문 서류와 공식 안내, 필요시 담당 전문가 | 권리 안전성이나 개인별 세금·대출 가능액을 이 조사만으로 확정하지 않는다. |

공식 자료가 제공하는 범위에도 한계가 있다. 국토교통부 실거래 자료는 계약일 기준이며 신고·해제로 달라질 수 있다. 단독·다가구 등 일부 유형은 공개 주소가 제한되므로 특정 광고 매물과 실거래를 무리하게 일치시키지 않는다. 현재 호가는 실거래 자료에서 얻을 수 없다. [공개 안내](https://rt.molit.go.kr/pt/info/info.do), [자료제공 유의사항](https://rt.molit.go.kr/pt/xls/xls.do), [공개 항목 안내](https://rt.molit.go.kr/pt/bbs/faqList.do).

## 숫자와 주장 기록

- 가격마다 **종류(실거래·호가·시세·분양가), 거래 또는 관찰 날짜, 면적과 거래 단위, 출처**를 붙인다. 전세가율은 같은 유형·면적대·시점의 매매와 전세 기준을 밝힐 때만 계산한다.
- 비교 통계에는 표본 범위·기간·건수를 함께 제시한다. 표본 부족, 해제 거래, 극단값, 층·수리·권리 차이를 확인한다. 근거 없는 ‘평균 시세’와 임의의 급매 소진율을 만들지 않는다.
- 각 핵심 결론을 **확인됨 / 일부 확인·추가 검증 필요 / 자료에서 추론 / 확인 불가** 중 자연스러운 말로 표시한다. 서로 다른 출처가 충돌하면 숨기지 않고 차이와 확인 시점을 설명한다.
- 가격 또는 사업 정보에 최신 자료 접근이 안 되면 마지막 확인 시점과 누락 내용을 명시한다. 이전에 본 가격을 현재가로 재사용하지 않는다.

## 해석과 미래 전망의 한계

- “무조건 오른다”, “확정 수혜”, “안전한 투자”, “적정 매수 시점”처럼 불확실성을 지우는 표현을 쓰지 않는다.
- 개발 계획은 민간 기대·검토·계획·인허가·착공·운영의 확인된 단계로 표현한다. 교통 신설만으로 모든 인근 물건의 가치가 오른다고 추론하지 않는다.
- 실거주와 투자, 전세·월세, 갈아타기의 판단 기준을 구분한다. 장점과 함께 가격 선반영, 공급, 유동성, 금리·규제, 유지비, 임대차와 권리 위험을 관련된 범위에서 제시한다.
- 미래 가격이나 수익률을 수치로 제시하려면 비교 표본과 가정·계산을 공개한다. 그렇지 않으면 조건별 시나리오와 관찰 지표만 제시한다.
- 세금, 대출, 청약 자격, 권리관계의 개인별 결론은 최신 규정과 서류, 전문가 확인 없이 확정하지 않는다.
