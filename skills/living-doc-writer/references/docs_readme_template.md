# 리빙독 문서 인덱스

이 디렉터리는 프로젝트의 최신 신뢰본 문서를 보관합니다. 아이디어, 디자인, 개발 착수뿐 아니라 의사결정, 진행 상태, 운영, 온보딩, 서비스 가이드, 데이터/보안, 성과 지표, 문서 운영처럼 계속 갱신되어야 하는 문서를 관리합니다.
여기 나열된 항목을 `living-doc-writer`가 우선적인 생성 및 갱신 대상으로 사용합니다.

## 운영 규칙
- 회의록은 사용자가 명시적으로 요청한 경우에만 작성합니다. 회의 결과는 위 상시 문서에 반영합니다.
- 넓은 문서 요청은 먼저 기획, 의사결정, 진행 상태, 운영/배포, 온보딩, QA, 서비스 가이드, 데이터/보안, 디자인 시스템/콘텐츠, 비즈니스/성과, 문서 운영 중 목적을 판별합니다.
- 기획 요청은 다시 아이디어 기획, 디자인 기획, 개발 착수 기획 중 현재 단계를 판별합니다.
- 아이디어가 불명확하면 기술/API/QA 문서를 만들지 않습니다.
- 디자인 방향이 불명확하면 개발용 `design-brief.md`로 확정하지 않고 디자인 기획 문서부터 만듭니다.
- 개발 착수 요청은 프로젝트, 요구사항, 화면, 디자인, 기술, 일정, QA 중 요청 범위에 필요한 문서를 함께 검토합니다.
- 운영, 보안, 개인정보, 과금, 사용자 공개 문서는 조용히 가정하지 않고 확인 필요 항목을 분리합니다.
- 프로젝트에 해당하지 않는 문서는 삭제하지 말고 `해당 없음` 사유를 남기거나 manifest에서 제외합니다.
- 모든 문서는 확정 사항, 가정, 미정 사항을 구분합니다.
