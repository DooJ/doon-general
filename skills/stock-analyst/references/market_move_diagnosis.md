# 현재 시장 움직임 진단

"왜 지금 장이 내리는가", "오늘 오른 이유가 무엇인가"처럼 이미 관측된 움직임의 설명을 요청받았을 때 사용한다. 원인 진단과 미래 전망을 별도 작업으로 취급한다. 사용자가 전망도 요청했다면 진단을 끝낸 뒤 조건부 시나리오를 제시한다. 자료의 최신성·출처·투자 위험 기준은 `source_and_safety.md`를 따른다.

## 1. 무엇이 움직였는지 먼저 확정

1. 시장과 지수·업종, 관측 구간(장중·장마감·최근 며칠), 기준 시각과 시간대를 확인한다. 실시간 자료가 없으면 확인 가능한 마지막 시각을 밝히고 `현재`라고 단정하지 않는다.
2. 지수 등락률만 보지 않는다. 상승·하락 종목 수, 주요 업종, 거래대금, 시가총액 상위 종목의 기여를 확인해 전반적 하락인지 일부 대형주의 영향인지 구분한다.
3. 다른 시장·선물, 환율, 국채금리, 원자재 가격과 투자자별 수급을 비교하되 각 자료의 거래 시간과 업데이트 시각이 다를 수 있음을 표시한다.

## 2. 원인 후보를 여러 층에서 조사

| 원인 층 | 확인할 자료 | 성급한 결론을 피할 점 |
|---|---|---|
| 기업·산업 | 실적, 가이던스, 공시, 업종별 등락, 대형주 기여 | 한 기업 악재를 전체 시장 원인으로 확대하지 않는다. |
| 거시·정책 | 금리, 물가, 고용, 중앙은행 발표, 환율, 정책 원문 | 발표 시각보다 먼저 시작한 움직임을 발표 탓으로 돌리지 않는다. |
| 해외 전이 | 주요 해외 지수·선물, 동종 업종, 글로벌 위험 선호 | 거래 시간 차이와 현지 고유 요인을 분리한다. |
| 수급·유동성 | 거래대금, 외국인·기관 거래, 선물·옵션, 대량 매매 | 동시 발생한 순매도를 단독 원인으로 확정하지 않는다. |
| 기대·포지셔닝 | 실적 예상과 실제 차이, 이전 상승 폭, 밸류에이션, 주요 가격대 | 뉴스가 없어도 기대 조정일 수 있지만 근거 없이 심리를 단정하지 않는다. |

시장·거래소 데이터, 기업·규제기관 공시, 중앙은행·통계기관 원문을 우선 확인한다. 언론 보도는 사건을 찾는 단서로 쓰고, 주요 설명은 가능한 한 원문 또는 여러 독립 자료로 대조한다.

## 3. 설명의 강도 판정

- `관측 사실`: 기준 시각이 확인된 가격, 수급, 발표와 공시 내용.
- `근거 있는 해석`: 사건의 시간 순서, 영향을 받은 업종·종목, 다른 시장과의 비교가 일관되는 설명. 근거와 반대 사례를 함께 적는다.
- `미확인 가설`: 그럴듯하지만 시각·범위·원문 자료가 부족한 설명. 확정 원인처럼 쓰지 않는다.

하나의 뉴스가 모든 하락을 설명한다고 가정하지 않는다. 여러 요인이 겹쳤으면 기여가 큰 설명과 보조 설명을 구분하고, 기여도를 계산할 근거가 없으면 숫자로 비중을 배분하지 않는다. 원인을 특정할 자료가 부족하면 `원인 불명` 또는 `부분 설명`이라고 명시한다.

## 4. 답변 형식

1. **현재 확인된 움직임**: 시장·구간·기준 시각, 지수와 업종·종목의 하락 또는 상승 범위.
2. **가장 설득력 있는 설명**: 원인 후보별 근거, 발생 순서, 설명 범위와 확실성.
3. **다른 가능성과 남은 공백**: 반대 근거, 아직 확인되지 않은 자료.
4. **다음 확인 지점**: 어떤 발표·가격·수급 변화가 현재 해석을 강화하거나 뒤집는지.

사용자가 미래 방향까지 물었을 때만 별도 `전망` 단락을 만들고 상승·중립·하락 조건과 무효화 조건을 제시한다. 현재 하락 이유만 묻는 요청을 자동으로 매수·매도 판단이나 종목 추천으로 확장하지 않는다.
