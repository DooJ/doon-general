# Stock Source And Safety Reference

주식, ETF, 지수, 금리, 환율, 섹터, 실적, 공시, 투자 시나리오를 다룰 때 사용하는 출처·안전 기준이다. 최신 가격이나 투자 판단에 영향을 주는 요청에서는 이 문서를 읽고 기준일과 출처를 명시한다.

기준 확인일: 2026-07-08

## 1. 답변 전 확인

| 확인 항목 | 기준 |
|---|---|
| 시장 | 한국/미국/기타 시장을 구분한다. |
| 자산 | 개별 주식, ETF, 지수, 선물, 옵션, 레버리지/인버스 여부를 구분한다. |
| 목적 | 단기 트레이딩, 장기 투자, 배당, 리밸런싱, 리스크 점검 중 무엇인지 분리한다. |
| 보유 여부 | 보유/미보유, 평균 단가, 비중, 목표 기간이 있으면 반영한다. |
| 기준 시각 | 가격, 환율, 금리, 공시, 뉴스의 기준일과 가능하면 기준 시각을 적는다. |

정보가 부족해도 개괄 분석은 가능하지만, 매수/매도 판단에 가까워질수록 목적·기간·손실 허용 범위를 확인한다.

## 2. 출처 우선순위

| 영역 | 1차 출처 | 보조 출처 | 주의 |
|---|---|---|---|
| 한국 기업 공시 | DART, KIND | 회사 IR, 거래소 안내 | 정정공시와 최근 보고서를 확인한다. |
| 미국 기업 공시 | SEC EDGAR | 회사 IR | 10-K, 10-Q, 8-K, S-1, proxy 등을 구분한다. |
| 가격/거래량 | 거래소, 공식 데이터, 신뢰 가능한 시세 데이터 | 증권사, 금융 포털 | 지연 시세 여부를 표시한다. |
| 거시 지표 | 한국은행 ECOS, FRED, 통계청, BLS, FOMC/Fed 자료 | 경제 뉴스 | 발표일, 수정치, 다음 발표일을 구분한다. |
| 실적 | 회사 IR, 공시, earnings release | 컨센서스 데이터, 뉴스 | 실제치/가이던스/컨센서스를 섞지 않는다. |
| 뉴스/테마 | 원문 보도자료, 규제기관, 회사 발표 | 언론 기사 | 루머와 공식 발표를 구분한다. |

출처 예시:

- DART: `https://dart.fss.or.kr/`
- SEC EDGAR: `https://www.sec.gov/edgar/search/`
- KRX KIND: `https://kind.krx.co.kr/`
- KRX Data: `https://data.krx.co.kr/`
- 한국은행 ECOS: `https://ecos.bok.or.kr/`
- FRED: `https://fred.stlouisfed.org/`

## 3. 사실, 추정, 의견 분리

| 유형 | 표현 방식 |
|---|---|
| 사실 | 출처와 기준일을 붙인다. |
| 추정 | “현재 자료 기준으로는”, “가능성이 있다”, “확인 필요”를 붙인다. |
| 시나리오 | 상승/중립/하락 조건과 무효화 조건을 같이 적는다. |
| 의견 | 투자자의 기간, 비중, 손실 허용 범위에 따라 달라질 수 있음을 표시한다. |

## 4. 금지 표현

- “무조건 오른다”, “확실히 간다”, “안전한 수익”, “원금 보장”처럼 결과를 보장하지 않는다.
- “지금 사라/팔아라”처럼 개인 맞춤 투자 지시로 단정하지 않는다.
- 단일 뉴스나 단일 차트 신호만으로 투자 결론을 내리지 않는다.
- 미확인 루머, 커뮤니티 글, 익명 출처를 사실처럼 쓰지 않는다.
- 레버리지, 옵션, 테마주, 급등주는 손실 가능성을 축소하지 않는다.

## 5. 리스크 표시 기준

| 상황 | 반드시 포함할 리스크 |
|---|---|
| 개별 종목 | 실적 하향, 밸류에이션 부담, 경쟁, 규제, 수급, 유동성 |
| 성장주 | 금리 민감도, 실적 가시성, dilution, 기대치 과열 |
| 배당주 | 배당 지속 가능성, 이익/현금흐름, 금리 대체재 |
| 바이오/신약 | 임상 실패, 승인 지연, 자금 조달, 이벤트 변동성 |
| 레버리지/인버스 | 복리 효과, 추적 오차, 단기 보유 전제 |
| 해외주식 | 환율, 세금, 시간외 변동, 공시 언어와 회계 기준 |

## 6. 출력 체크리스트

- 기준일/기준시각을 표시했는가?
- 사용한 주요 출처를 요약하고, 후보 발굴에서는 후보별 핵심 근거의 원문 출처를 확인할 수 있게 했는가?
- 가격, 실적, 공시, 뉴스, 전망을 분리했는가?
- 현재 움직임의 원인 진단에서는 관측 사실과 원인 해석을 구분했는가? 미래 전망을 요청받았다면 상승/중립/하락 시나리오와 무효화 조건을 같이 제시했는가?
- 사용자의 투자 목적이 없으면 일반 정보 제공으로 제한했는가?
- 마지막에 투자 손실 가능성과 개인 판단 필요성을 짧게 고지했는가?
