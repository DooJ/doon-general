# 종목 후보 발굴 계약

사용자가 종목을 지정하지 않은 발굴 요청 또는 지정 종목의 대안 비교 요청에서 분석할 회사를 직접 찾는다. 발굴한 종목은 `SKILL.md`의 공통 분석 기준으로 넘긴다. 사용자가 요청한 시장·기간·목적을 우선하고, 발굴 주기를 임의로 정하거나 자동 감시가 실행 중이라고 주장하지 않는다. 최신 자료의 출처·기준 시각과 금융 안전 기준은 `source_and_safety.md`를 따른다.

## 1. 검색 범위와 자료 범위

1. 시장, 판단 기간, 선호·제외 산업, 위험 허용 조건이 주어졌으면 그대로 적용한다. 누락된 조건이 후보의 적합성을 크게 바꾸면 짧게 확인하고, 그 외에는 일반적인 가정을 밝힌 뒤 탐색한다.
2. 실제로 확인할 수 있는 상장사 목록과 가격·공시·재무자료를 기준으로 탐색 범위를 적는다. 전 시장을 조회하지 않았다면 `전체 시장 스캔`이라고 표현하지 않는다.
3. 국내는 KRX 종목·시세와 DART/KIND 공시, 미국은 거래소 종목·시세와 SEC EDGAR 공시를 우선한다. 보조 데이터의 지연·누락, 회계 기간·통화·수정 공시 차이를 확인한다.
4. 자료 접근 범위가 좁으면 확인한 표본과 빠진 시장·기업군을 표시한다. 검색 결과나 뉴스 노출 순위를 전체 종목 순위로 둔갑시키지 않는다.

## 2. 서로 다른 경로에서 후보 생성

사용자 조건에 맞는 경로를 복수로 적용한다. 한 경로의 신호만으로 투자 결론을 만들지 않으며, 같은 회사가 여러 경로에 걸리면 근거를 합쳐 중복을 제거한다.

| 발굴 경로 | 먼저 찾을 변화 | 확인해야 할 반대 근거 |
|---|---|---|
| 실적·사업 개선 | 매출, 이익률, 잉여현금흐름, 수주, 가이던스의 개선과 지속성 | 일회성 이익, 회계 변경, 희석, 운전자본 악화 |
| 산업·거시 변화 | 수요, 공급, 금리, 환율, 정책 변화와 개별 기업의 실제 수혜 연결 | 산업 성장에도 기업의 점유율·수익성이 악화하는지 |
| 공시·사건 | 실적 발표, 계약, 제품, 승인, 자본 배분처럼 전망을 바꿀 공식 사건 | 실행 지연, 조건부 계약, 이미 반영된 기대 |
| 가격과 기대의 차이 | 동종 기업·과거 범위·합리적 시나리오와 비교한 현재 가격 | 낮은 배수의 구조적 이유, 과한 성장 가정 |
| 가격·수급의 변화 | 거래량, 추세, 변동성, 투자자별 수급에서 추가 조사가 필요한 이례적 변화 | 뉴스 없는 급등, 낮은 유동성, 단기 수급의 소멸 |
| 회복·역발상 | 일시적 악재 뒤 사업·재무의 회복 가능성과 과도한 가격 반응 | 영구적 경쟁력 훼손, 자금 조달·상장 유지 위험 |

고배당·방어주처럼 성장률보다 현금 분배와 안정성이 중요한 목적이면 배당의 지속 가능성, 현금흐름, 부채를 별도 경로로 본다. 산업별 회계·성장 단계가 다르므로 모든 기업에 동일한 숫자 임계값을 적용하지 않는다.

## 3. 후보 검증과 제외

1. 발굴 신호가 나온 뒤 최근 정기·수시 공시와 회사 발표의 원문을 확인한다. 가격과 거래량은 기준 시각과 지연 여부를 적는다. 뉴스·소셜 게시물은 발견 단서일 수 있지만 단독 사실 근거로 쓰지 않는다.
2. 사업의 돈 버는 구조, 경쟁력, 재무 건전성, 미래 현금창출력, 현재 가격에 반영된 성장 기대를 확인한다. 동종 기업 비교는 사업 구성과 회계 기준의 차이를 함께 적는다.
3. 예상 실적과 실제 실적, 발표 시점, 주가 반응을 분리한다. 실적이 좋아도 시장 예상보다 약하거나 가격에 이미 반영됐으면 상승 근거로 단정하지 않는다.
4. 후보마다 `왜 지금`, 핵심 근거, 가장 강한 반대 논거, 다음에 확인할 사건, 판단이 무효가 되는 조건을 적는다.
5. 공시·재무 자료가 부족하거나 유동성·희석·회계·규제 위험을 확인할 수 없으면 `추가 검증` 또는 `제외`로 둔다. 적합한 후보가 없으면 후보 없음과 그 이유를 제시한다.

## 4. 결과와 심층 분석 인계

후보 발굴은 매수 권고가 아니라 심층 분석할 회사를 좁히는 단계다. 지정 종목과 함께 비교할 때는 각 종목의 출발 경로를 구분하고 동일한 분석 기준을 적용한다. 사용자에게 다음을 짧은 표로 보여준다.

| 항목 | 내용 |
|---|---|
| 탐색 범위 | 시장, 자료 범위, 적용·제외 조건, 기준 시각 |
| 후보 | 기업·ticker, `스킬 발굴` 경로와 현재 확인 상태 |
| 투자 가설 | 기업 가치가 달라질 이유와 현재 가격에 반영된 기대 |
| 반대 근거 | 하방 위험, 자료 공백, 판단 무효화 조건 |
| 다음 검증 | 확인할 공시·실적·사건과 확인 시점 |

여러 경로에서 찾았더라도 한 산업에만 후보가 몰렸으면 집중을 표시한다. 후보별 근거의 강약과 검증 상태를 구분하고, 충분히 확인된 후보만 개별 종목 심층 분석으로 넘긴다. 사용자가 저장을 요청하지 않으면 후보 목록을 파일이나 상시 감시 목록으로 만들지 않는다.
