# Guide Output Patterns

서비스 가이드는 실제 제품과 분리된 설명 산출물이다. 먼저 어디에 어떤 형태로 둘지 정한다.

## 출력 형태

| 형태 | 위치 예시 | 선택 기준 |
|---|---|---|
| 독립 정적 HTML | `guide/index.html` | 앱 빌드 없이 열람해야 하거나, 제품 코드와 가이드 변경을 분리할 때 |
| 문서형 정적 HTML | `docs/<feature>-guide/index.html` | 특정 기능/장비/운영 화면 문서로 관리할 때 |
| 앱 내부 라우트 | `/guide`, `app/guide/page.tsx` | 실제 앱 컴포넌트와 상태를 재사용해 가이드 모드를 제공할 때 |
| 이동용 엔트리 | `service-guide.html` | 예전 링크를 유지하거나 새 가이드 위치로 안내할 때 |

앱 내부 라우트를 쓰더라도 실제 제품 페이지를 iframe처럼 그대로 로드했다는 뜻이 아니다. 실제 컴포넌트 재사용, 실행 캡처 기반, UI 재현 중 어떤 방식인지 명시한다. 각 방식의 한계도 남긴다. 캡처 기반은 이미지 교체·반응형 크기에 맞춰 클릭 위치를 검증해야 하고, UI 재현은 최신 실행 화면과 나란히 비교해야 한다.

## 권장 파일 구성

작은 가이드:

```text
guide/
├── README.md
└── index.html
```

중간 이상 가이드:

```text
guide/
├── README.md
├── index.html
├── styles.css
├── script.js
├── assets/
└── tools/
```

- `README.md`: 범위, 실행 방법, 근거 파일, 갱신 트리거, 검증 방법을 기록한다.
- `index.html`: 화면 구조, 설명 패널, 실제 실행 캡처 또는 근거 있는 재현 화면을 담는다.
- `styles.css`: 실제 화면 비율, 강조 박스, 반응형 레이아웃, 확대 패널을 분리한다.
- `script.js`: 화면 전환, 핫스팟, 언어 전환, 상태 전환, 이전/다음 순서를 분리한다.
- `assets/`: 앱 아이콘, 캡쳐 이미지, 실제 화면 리소스.
- `tools/`: Android XML, strings, i18n JSON, 화면 캡쳐를 HTML/데이터로 변환하는 보조 스크립트.

## README에 남길 것

- 최종 확인일
- 가이드 대상 서비스, 요청된 화면·기능 목록과 포함·미확인 항목
- 화면별 실제 코드/리소스/캡처 기준과 실행 확인 여부
- 주요 조작 요소의 근거 매핑 및 검증된 수
- mock, 예정, 미연결 범위
- 화면 비율, 언어, 방향, 상태 전환 기준
- 갱신 트리거: 어떤 코드/리소스가 바뀌면 가이드도 바꿔야 하는지
- 검증 방법: 로컬 실행, 클릭 흐름, 콘솔 오류, 반응형, 언어/상태 전환
