## 검증 방법

1. 로컬에서 가이드 페이지를 연다.
2. 좌측 메뉴를 바꿨을 때 중앙 화면과 설명 대상도 실제로 바뀌는지 확인한다.
3. 주요 요소를 각각 클릭·키보드로 선택해 올바른 설명이 열리고 대상 ID가 누락·중복되지 않는지 확인한다.
4. 포함한 주요 상태와 오류 화면을 전환한다.
5. 다국어가 있으면 화면 문구와 설명 패널이 함께 바뀌는지 확인한다.
6. 브라우저 콘솔 오류와 모바일/데스크톱 레이아웃 깨짐을 확인한다.
